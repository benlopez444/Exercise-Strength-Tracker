# Exercise Strength Tracker
## Goal
Create a program where users can quickly input 
entries of exercises and compare them to past entries
to receive an improvement score/percentage
### MVP Scope
A program that receives input of weights, reps, and sets
for an exercise and compares it to past entries to
calcualate an improvement score/percentage
### Future Plans
A visually appealing UI that displays charts of
improvement. A leaderboard displaying the strongest
and most improved users. A personal ranking of a 
user's strongest exercise
### Stack
Java ArrayLists
Java IO
Java Scanner
